# OZAAR | Complete UX Case Study

## Overview

This repository showcases the complete UX case study for **OZAAR**, a mobile application designed to simplify tool rentals and technician hiring through a seamless, user-centered experience.

Developed as the capstone project for the **Vortex Tech UI/UX Internship Program**, this case study documents the complete design journey—from identifying the problem and understanding user needs to creating wireframes, designing high-fidelity interfaces, building an interactive prototype, and reflecting on the overall design process.

## Problem Statement

Finding reliable tools or skilled technicians for short-term tasks can be time-consuming and inconvenient. OZAAR addresses this challenge by providing a single platform where users can easily rent tools, hire verified technicians, complete secure identity verification, and track their bookings through an intuitive mobile experience.
